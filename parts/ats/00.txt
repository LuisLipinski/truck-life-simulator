      <div class="notice"><strong>Regra principal:</strong> não altere os nomes da primeira coluna (<code>CAREER</code>, <code>STATE</code>, <code>TRIP</code> etc.) nem os cabeçalhos. Linhas que você não precisa podem ser deixadas sem registros.</div>

      <h3>1. Linha de identificação</h3>
      <p><code>ATS_CAREER_BACKUP,2</code> identifica o arquivo como um CSV compatível com o simulador. Não altere essa linha.</p>

      <h3>2. CAREER — dados do personagem</h3>
      <div class="table-wrap"><table><tr><th>Coluna</th><th>O que significa</th></tr>
      <tr><td>id</td><td>Pode ficar vazio. Ao importar, o site cria um novo ID automaticamente.</td></tr>
      <tr><td>driverName</td><td>Nome do motorista. Obrigatório.</td></tr>
      <tr><td>city</td><td>Cidade-base da carreira, por exemplo <code>Los Angeles, CA</code>.</td></tr>
      <tr><td>company</td><td>Nome da transportadora onde o personagem trabalha.</td></tr>
      <tr><td>arrivalBalance</td><td>Dinheiro que o personagem trouxe ao chegar aos EUA.</td></tr>
      <tr><td>initialBalance</td><td>Saldo disponível depois dos gastos iniciais de mudança.</td></tr>
      <tr><td>bio</td><td>Biografia do personagem. Texto livre.</td></tr>
      <tr><td>createdAt</td><td>Data de criação. Pode ficar vazia; o site preencherá na importação.</td></tr></table></div>

      <h3>3. SETUP_COST — gastos para começar a morar</h3>
      <p>Uma linha por gasto inicial. <code>name</code> é o identificador do gasto e <code>value</code> é o valor em dólares. Os nomes sugeridos são: <code>rent</code>, <code>deposit</code>, <code>license</code>, <code>groceries</code>, <code>home</code>, <code>phone</code>, <code>internet</code> e <code>transit</code>.</p>

      <h3>4. STATE — situação atual da carreira</h3>
      <div class="table-wrap"><table><tr><th>Coluna</th><th>O que significa</th></tr>
      <tr><td>balance</td><td>Saldo atual da conta.</td></tr><tr><td>careerLevel</td><td>Nível atual: 1, 2 ou 3.</td></tr><tr><td>currentWeek</td><td>Número da semana de trabalho aberta no momento.</td></tr><tr><td>academyLevel2</td><td>Use 1 se o Academy do Nível 2 já foi concluído; 0 se não.</td></tr><tr><td>academyLevel3</td><td>Use 1 se o Academy do Nível 3 já foi concluído; 0 se não.</td></tr><tr><td>hazmatQualified</td><td>Use 1 se a qualificação HazMat já foi obtida; 0 se não.</td></tr></table></div>

      <h3>5. TRIP — viagens</h3>
      <p>Adicione uma linha <code>TRIP</code> para cada viagem. <code>week</code> define a semana; <code>departureAt</code> e <code>arrivalAt</code> são obrigatórios e usam o formato <code>AAAA-MM-DDTHH:MM</code>; <code>origin</code>/<code>destination</code> são cidades; <code>originCompany</code>/<code>destinationCompany</code> são empresas; <code>cargo</code> é a carga; <code>type</code> use <code>Loaded</code> ou <code>Deadhead</code>; <code>payCategory</code> use <code>normal</code>, <code>hazmat</code>, <code>doubles</code>, <code>hazmat_doubles</code> ou <code>deadhead</code>; <code>miles</code> é a distância.</p>
      <div class="notice"><strong>Per diem:</strong> não é preenchido por viagem. O sistema calcula os dias qualificáveis automaticamente com base em <code>departureAt</code> e <code>arrivalAt</code>. Uma viagem que começa e termina no mesmo dia não gera per diem.</div>

      <h3>6. HISTORY — movimentações financeiras</h3>
      <p>Opcional. Guarda entradas e saídas antigas. Colunas: <code>date</code>, <code>type</code>, <code>desc</code>, <code>value</code> e <code>balance</code>.</p>

      <h3>7. EXPENSE — gastos personalizados</h3>
      <p>Opcional. <code>name</code> é o gasto, <code>value</code> é o valor e <code>monthly</code> deve ser <code>1</code> para entrar no desconto mensal automático ou <code>0</code> para não entrar.</p>

      <h3>8. INCIDENT — infrações e acidentes</h3>
      <p>Opcional. Uma linha por ocorrência. Informe tipo, data, hora, rota, descrição, valor e método de cobrança. Em <code>chargeMethod</code>, use <code>balance</code> para desconto imediato ou <code>payslip</code> para desconto no holerite. <code>remaining</code> é o valor ainda pendente.</p>

      <h3>9. CLOSED_WEEK — semanas já fechadas</h3>
      <p>Opcional. Use para importar holerites/semanas antigas. Se estiver começando uma carreira nova no Excel, pode deixar somente o cabeçalho dessa seção e preencher as viagens em <code>TRIP</code>.</p>

      <div class="notice"><strong>Mais simples para uma carreira nova:</strong> preencha CAREER, SETUP_COST e STATE. Depois adicione TRIP conforme necessário. HISTORY, EXPENSE, INCIDENT e CLOSED_WEEK são opcionais.</div>
      <h3>Glossário dos termos do modelo</h3>
      <ul>
        <li><strong>Loaded:</strong> viagem com carga.</li>
        <li><strong>Deadhead:</strong> viagem vazia.</li>
        <li><strong>HazMat:</strong> hazardous materials; carga perigosa que exige qualificação específica.</li>
        <li><strong>Doubles:</strong> dois reboques/bitrem na adaptação da simulação.</li>
        <li><strong>CPM:</strong> valor por milha.</li>
        <li><strong>Per diem:</strong> diária de viagem calculada automaticamente pelos dias válidos entre saída e chegada.</li>
        <li><strong>OTR:</strong> viagens de longa distância com pernoite fora da base.</li>
      </ul>

const CAREERS_KEY='ats_careers_v1';
function money(v){return new Intl.NumberFormat('en-US',{style:'currency',currency:'USD'}).format(Number(v)||0)}
function esc(v){return String(v??'').replace(/[&<>"']/g,c=>({'&':'&amp;','<':'&lt;','>':'&gt;','"':'&quot;',"'":'&#039;'}[c]))}
function loadCareers(){try{return JSON.parse(localStorage.getItem(CAREERS_KEY)||'[]')}catch{return []}}
function saveCareers(items){localStorage.setItem(CAREERS_KEY,JSON.stringify(items))}
function render(){const list=document.getElementById('careerList');const careers=loadCareers();if(!careers.length){list.innerHTML='<div class="empty">Nenhuma carreira criada ainda.<br>Crie ou importe a primeira para começar.</div>';return;}list.innerHTML=careers.map(c=>`<article class="card"><h2>${esc(c.driverName)}</h2><div class="meta"><strong>Cidade:</strong> ${esc(c.city)}<br><strong>Empresa:</strong> ${esc(c.company)}<br><strong>Saldo inicial:</strong> ${money(c.initialBalance)}</div><div class="bio">${esc(c.bio||'Sem biografia.')}</div><div class="row"><a class="btn" href="fases.html?career=${encodeURIComponent(c.id)}">Continuar</a><button class="btn danger" onclick="deleteCareer('${c.id}')">Excluir</button></div></article>`).join('')}
function deleteCareer(id){if(!confirm('Excluir esta carreira e todos os dados dela?'))return;let careers=loadCareers().filter(c=>c.id!==id);saveCareers(careers);localStorage.removeItem('ats_phase1_state_v4_'+id);render()}
function openTutorial(){document.getElementById('csvTutorial').classList.add('open')}
function closeTutorial(){document.getElementById('csvTutorial').classList.remove('open')}
function csvEscape(value){const text=String(value??'');return '"'+text.replace(/"/g,'""')+'"'}
